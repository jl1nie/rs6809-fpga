# 6809 machine (Multicomp09-compatible): registers

The specification is rs6809's `src/machine.rs`; the hardware is in `m6809/`. Differences from the emulator are marked **FPGA**.

## Memory map

| Address | Device |
|---|---|
| `$0000`-`$FFFF` | RAM through the MMU (8 KiB banks of up to 1 MiB in the SDRAM) |
| `$E000`-`$FFFF` | 8 KiB boot ROM (block RAM) while ROMDIS is clear; writes are ignored |
| `$FFD0`/`$FFD1` | ACIA 1 (console): status/control, data |
| `$FFD2`-`$FFD7` | additional ACIAs: not fitted (`$FFD2`/`$FFD4` read `$02`, the others `$FF`) |
| `$FFD8`-`$FFDC` | SD controller |
| `$FFDD` | 50 Hz timer |
| `$FFDE`/`$FFDF` | MMU mapper / map entry (read `$FF`) |

Banks past the RAM read `$FF`; writes to them, and to write-protected slots, are ignored.

## ACIA ($FFD0/$FFD1)

| Register | Read | Write |
|---|---|---|
| `$FFD0` | bit 0 RDRF (a byte received), bit 1 TDRE (room in the transmit FIFO), bit 2 DCD (0), bit 7 IRQ | control: `xxxxxx11` master reset (control 0, receive FIFO emptied); otherwise stored |
| `$FFD1` | received byte (`$FF` when none) | byte to send |

IRQ = (control bit 7 and RDRF) or (control bits 6-5 = `01` and TDRE).
**FPGA**: transmission takes real time (115200 baud), so TDRE follows a 16-byte FIFO (the emulator sends at once); the receive FIFO holds 64 bytes.

## SD controller ($FFD8-$FFDC)

| Register | Read | Write |
|---|---|---|
| `$FFD8` | data byte (reading) | data byte (writing) |
| `$FFD9` | status | command: 0 read sector, 1 write sector (ignored unless idle) |
| `$FFDA`/`$FFDB`/`$FFDC` | `$FF` | LBA bits 7-0, 15-8, 22-16 |

Status: `$80` idle, `$E0` a byte to read, `$A0` bytes may be written, `$90` no card.
**FPGA**: the card takes time, so two more states appear, as on Grant Searle's controller (bit 5 busy): `$A0` while a sector is read from the card (before `$E0`), `$20` while it is written (after the 512th byte, before `$80`); `$90` while the card initialises. The LBA is the card's sector (512-byte sectors, SDHC/SDXC).

## Timer ($FFDD)

Read: the register. Write: bit 1 enables the tick; a write with bit 7 set clears bit 7. Every 20 ms with bit 1 set, bit 7 is set and raises IRQ.
**FPGA**: 50 Hz real time (the emulator counts 20000 CPU cycles). It stands still while the ICE has the CPU stopped.

## MMU ($FFDE/$FFDF)

`$FFDE` (writes with bit 4 clear): bits 3-0 the map entry `$FFDF` writes, bit 5 MMU on, bit 6 task, bit 7 ROMDIS.
Fixed top: `$FE00`-`$FFFF` bypass the map after the handshake: a write with bit 5 set and bit 7 clear while the mapper has bits 7 and 5 set (ROMDIS stays set meanwhile); a write with bit 5 clear ends it.
`$FFDF`: map entry (bit 7 write protect, bits 6-0 bank). Translation: MMU off or fixed top → the address itself; otherwise `map[task * 8 + slot]`, 8 KiB banks.
This follows rs6809 (`refresh_mapping`, `physical`), which follows the kit's emulator `exec09/miscsbc.c`.

## Interrupts

IRQ = timer bit 7 or ACIA IRQ. FIRQ and NMI are not used. **FPGA**: held off while the ICE steps.

## CPU

cpu09p (John Kent, GPL-3.0) from multicomp6809, with the ICE's ports (tools/patch-cpu09p.py). It is not cycle-exact: rs6809's cycle counts and the board's differ, and software must not depend on them (time comes from the timer). The CPU runs from the 32.4 MHz clock with a clock enable every other clock; accesses to the SDRAM stretch the cycle (about 5 to 8 MHz equivalent).

## Reset

S2, or the ICE: the CPU, the MMU, ROMDIS, the timer, the ACIA and the SD controller start again; RAM and the card keep their contents (rs6809's `reset_hardware`).
